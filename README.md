# 🤝 Карта Взаимопомощи

Платформа для создания сообщества взаимопомощи, где люди могут:
- Предлагать свои услуги и помощь
- Искать помощь в своем районе
- Создавать и обсуждать инициативы и идеи

## 🚀 Возможности

### Для пользователей:
- ✅ Регистрация и личный кабинет
- ✅ Интерактивная карта с отметками
- ✅ Добавление отметок о помощи, которую вы предлагаете
- ✅ Поиск помощи в вашем районе
- ✅ Создание и просмотр инициатив
- ✅ Фильтрация отметок по типам
- ✅ Просмотр профилей пользователей
- ✅ История своих отметок

## 🛠️ Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ванильный)
- **Карта**: Leaflet.js + OpenStreetMap
- **Хранилище**: localStorage (браузер)
- **Без бэкенда**: 100% клиентское приложение

## 🚀 Быстрый старт

1. Откройте `index.html` в браузере
2. Нажмите "Регистрация" и создавайте аккаунт
3. После входа нажмите "+ Добавить отметку"
4. Выберите тип (помощь, поиск или инициатива)
5. Заполните информацию и добавьте на карту
6. Другие пользователи смогут видеть вашу отметку!

## 👤 Профиль

Ваш профиль содержит:
- Личная информация
- Все ваши отметки на карте
- Дату присоединения
- Возможность редактирования информации

## 🗺️ Как работает карта

- Карта показывает все активные отметки пользователей
- Разные цвета и значки для разных типов отметок
- Нажмите на отметку, чтобы увидеть подробную информацию
- Фильтруйте отметки слева в боковой панели
- Нажмите на отметку в списке, чтобы перейти к ней на карте

## 💾 Хранение данных

Все данные хранятся в localStorage вашего браузера:
- Аккаунты пользователей
- Все отметки на карте
- Информация о профилях

**Примечание**: Данные удаляются, если вы очистите кэш браузера.
